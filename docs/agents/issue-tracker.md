# Issue tracker convention

The canonical issue tracker is [GitHub Issues for `ayisuplus/voxelgym`](https://github.com/ayisuplus/voxelgym/issues), selected from the repository's `origin` remote.

- Create and update durable work items in that tracker.
- Refer to work items as `#<number>` when the repository is unambiguous, or as `ayisuplus/voxelgym#<number>` across repositories.
- Use the labels recorded in [triage-labels.md](triage-labels.md) for workflow state. Type labels such as `bug`, `documentation`, and `enhancement` are orthogonal.
- Local notes under `.scratch/`, if introduced, are temporary working material and are not canonical tickets.
